    FFmpeg 安装指引

    请在运行声记服务的电脑上完成以下操作。

    1. 从下载页的 Windows 栏选择适合系统架构的静态版，下载并解压。
    2. 把解压后 bin 目录里的 ffmpeg.exe 复制到声记 EXE 所在目录。
    3. 回到这个窗口，点击「重新检测」。已选择的视频会保留。

    如果声记目录需要管理员权限，可在 Windows 搜索「编辑帐户的环境变量」，在用户变量 Path 中加入 FFmpeg 的 bin 目录，然后重启声记。

    按下载页说明安装对应系统的 FFmpeg。把可执行文件放在声记程序旁，或加入 PATH 后重启声记服务，再重新检测。

    请检查 FFmpeg 版本是否匹配系统架构，以及解压文件是否完整。若设置过 SHENGJI_FFMPEG，请核对该路径并重启服务。
